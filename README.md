# Amazon-Clone-Homepage-HTML-CSS

A front-end **Amazon Homepage Clone** built using **pure HTML and CSS**.  
This project replicates the design and layout of Amazon's main homepage, including the header, search bar, hero section, and footer.

---

## 🚀 Features

- 🧭 Fully functional Amazon-style navigation bar (logo, location, search, cart)
- 🖼️ Hero section with background banner
- 🎨 Product showcase grid layout
- 🦶 Multi-section Amazon footer
- ⚡ Smooth hover effects and responsive design practices

---

## 🧰 Technologies Used

- **HTML5** for structure  
- **CSS3 (Flexbox)** for layout and design  
- **Font Awesome** for icons  
- **Custom Amazon images** for realistic look
